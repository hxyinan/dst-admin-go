新增可选 Steam 账号登录，默认继续使用匿名登录。

- 在 **游戏服务端管理 → 对应节点 → Steam 登录** 配置账号并验证。支持 Steam Guard 邮件验证码、手机验证器和手机批准。
- 本机和 Agent 的游戏安装、游戏更新及模组下载共用该节点的登录设置；使用同一 SteamCMD 的安装位置共用账号。Agent 自行登录和下载。
- 密码加密保存在运行节点，不返回页面，也不写入进程参数、任务日志或 Agent 操作历史。自动下载需要人工验证时会明确失败，不会无限等待或切换匿名。
- 修复 Agent 登录设置与游戏安装的租约冲突、下载取消或磁盘写入失败被误判为成功，以及账号名和密码中的关键词干扰登录状态的问题。
- 统一支持 SteamCMD 可执行文件、安装目录和 PATH 命令。凭据或密钥损坏时，可在页面确认重置对应 SteamCMD 的登录设置，其他账号、游戏文件和存档不受影响。

**从 v1.2.6 升级：** 在 **系统设置 → 软件更新** 检查新版并更新控制端及内置前端，无需重新拉取镜像。远端 Agent 在 **机器详情 → 诊断** 单独升级后才支持 Steam 账号登录。`v1.2.1` 及更早版本需先更新镜像或使用完整安装包，以启用页面在线更新。

Steam 账号登录不能解决网络、磁盘空间或文件权限问题。登录行为已通过模拟 SteamCMD 和 Agent 回归验证，未使用真实 Steam 账号进行验证。

Optional Steam account login is now available. Anonymous login remains the default.

- Configure and verify an account under **Game server management → selected node → Steam login**. Steam Guard email codes, authenticator codes and mobile approval are supported.
- Game installation, game updates and mod downloads share node-local login settings. Installations using the same SteamCMD share an account. Agents log in and download directly.
- Passwords are encrypted on the runtime node and never returned to the UI or included in process arguments, task logs or Agent operation history. Unattended downloads requiring verification fail clearly instead of waiting indefinitely or switching to anonymous.
- Fix independent Agent lease scopes for login and installation, zero-exit download cancellation and storage failures, and login-state misclassification caused by keywords in credentials.
- Accept a SteamCMD executable, installation directory or command in PATH consistently. Unreadable credentials or keys can be reset after confirmation in the UI without changing other accounts, game files or saves.

**Upgrade from v1.2.6:** check for updates under **System settings → Software updates** to update the Controller and embedded UI without pulling a new image. Upgrade remote Agents separately under **Machine details → Diagnostics** before using account login. Versions up to `v1.2.1` require a full image or native-package update first to enable online updates.

Account login does not fix network, storage or filesystem permission errors. Login behavior was verified with simulated SteamCMD processes and Agent regression tests, without a real Steam account.
