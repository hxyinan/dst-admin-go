新增邮箱与自定义 Webhook 通知，入口为 **系统设置 → 通知**；保存后立即生效。

- 配置多个独立渠道，选择房间启停、备份恢复、游戏与模组管理、Agent 连接变化、登录异常和发现新版等事件，也可仅接收失败或异常。
- 邮箱支持实际发送、多收件人和测试邮件。Webhook 支持自定义地址、请求头、JSON / 纯文本模板，并提供企业微信、钉钉、飞书机器人预设。
- 在页面发送自定义消息、查看发送记录及失败原因，并按需重新发送。队列持久化，重复任务与版本事件去重；没有待发送消息时发送器休眠。
- Webhook 凭据加密保存，不返回页面明文；任务通知不转发原始命令输出、密码或任意日志。备份管理数据时需同时保留配置目录中的 `notifications/webhook.key`。
- 管理端顶部、软件更新页和 Agent 更新提示改为黄色提醒。手机通知页面直接显示发送状态，渠道操作按钮独立排列。

**从 v1.2.7 升级：** 在 **系统设置 → 软件更新** 检查并更新控制端和内置前端，无需重新拉取镜像。通知由管理端统一发送，已有 Agent 无需为通知功能单独升级。配置、数据库和游戏存档保留。使用更早版本的升级要求见[更新说明](https://github.com/lcy0828/dst-admin-go/blob/master/docs/deployment-and-rollback.md#页面在线更新)。

SMTP 连接测试不发送邮件，渠道的「测试发送」才会实际发送。发送记录的成功表示收件服务器接受消息；最终入箱取决于邮件服务。Webhook 支持固定令牌，暂不支持机器人动态签名。完整配置示例见[通知说明](https://github.com/lcy0828/dst-admin-go/blob/master/docs/notifications.md)。

Email and custom Webhook notifications are available under **System settings → Notifications**. Saved changes take effect immediately.

- Configure independent channels and subscriptions for room operations, backups and restores, game and mod management, Agent connections, blocked sign-ins and new releases. Filter to failures and warnings when needed.
- Email supports real delivery, multiple recipients and test messages. Webhooks support custom URLs, headers, JSON / plain-text templates, and WeCom, DingTalk and Feishu presets.
- Send custom messages, inspect delivery history and failures, and resend when needed. The persistent queue deduplicates task and version events, with an idle worker when no deliveries are pending.
- Webhook credentials are encrypted and never returned in plaintext. Task notifications exclude raw command output, passwords and arbitrary logs. Include `notifications/webhook.key` from the configuration directory in management-data backups.
- Yellow update alerts are now shown in the header, software settings and Agent update UI. Mobile delivery history shows status directly, with separate channel action controls.

**Upgrade from v1.2.7:** update the Controller and embedded UI under **System settings → Software updates**, without pulling a new image. The Controller sends notifications; existing Agents do not require a separate upgrade for this feature. Configuration, database and game saves are preserved. See the [upgrade guide](https://github.com/lcy0828/dst-admin-go/blob/master/docs/deployment-and-rollback.en.md#online-updates) for older versions.

The SMTP connection test does not send email; a channel test does. A successful delivery record means the receiving server accepted the message, with final inbox delivery depending on the mail service. Fixed-token Webhooks are supported; dynamic bot signing is not yet available. See the [notification guide](https://github.com/lcy0828/dst-admin-go/blob/master/docs/notifications.en.md).
